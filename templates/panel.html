Acesso a Credenciais (Avançado)

                        

                            

                                
                                

                                    Comando: reg save HKLM\sam C:\Users\Public\sam.save && reg save HKLM\system C:\Users\Public\system.save

                                    Descrição: Salva os "hives" do registro SAM e SYSTEM, que contêm os hashes das senhas de usuários locais. Requer privilégios de Administrador. Use com responsabilidade em ambientes controlados.
                                

                            


                            

                                
                                

                                    Comando: runas /user:DOMAIN\user /savecred "cmd.exe"

                                    Descrição: Usa credenciais de outro usuário para executar um processo. A flag /savecred armazena a senha no Gerenciador de Credenciais do Windows.
                                

                            


                            

                                
                                

                                    Descrição: Abre a interface de credenciais (Gerenciador de Credenciais). Útil para identificar credenciais armazenadas localmente.

                                    Descrição: Ferramenta nativa para controlar o Firewall do Windows. Requer privilégios de Administrador.

Requer privilégios de Administrador.

                                    Descrição: Adiciona chave de execução automática no logon do usuário.

                                    Descrição: Ferramenta legado para transferir arquivos através do serviço BITS (pode ser usada para download silencioso). Disponibilidade varia entre versões do Windows.
